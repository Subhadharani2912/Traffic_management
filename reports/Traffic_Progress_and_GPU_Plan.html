4. GPU server plan

Training is the only step that needs the GPU. Copy weights back to this laptop. The existing detector already loads emergency_best.pt.

  1. Use NVIDIA + CUDA PyTorch (T4 / RTX 3060+ is enough for YOLOv8n). Confirm torch.cuda.is_available() is True.
  2. Copy this project, or at least scripts/train.py, dataset/emergency_compact (or emergency_indian), and requirements.txt.
  3. If compact set is missing: python scripts/prepare_indian_emergency.py
  4. Train (full data, no CPU --fraction):
python scripts/train.py --emergency --device 0 --batch 16 --epochs 50 --imgsz 640 --patience 15

If VRAM is 16 GB or more, use --batch 32. Output: models/emergency_best.pt.

  1. Copy emergency_best.pt to Traffic_management/models/emergency_best.pt on this PC. Config already points there. No detector rewrite.
  2. Evaluate, then run videos/input/Emergency_Ambulance.mp4.
python scripts/evaluate.py --emergency --data dataset/emergency_compact/data.yaml

What not to redo on the GPU

Do not rebuild the dashboard, tracker, or preemption. Do not train on COCO alone. Do not depend on Roboflow hosted inference unless you accept an online API.
